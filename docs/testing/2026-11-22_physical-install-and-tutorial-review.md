## 你先手测这五项

有旧进度时，从章节目录回看已解锁章节，不必清空课程进度或应用数据。

- [ ] **原数据**：打开应用，确认旧项目、当前课程章节和已完成标记仍在。
- [ ] **一键工程**：进入第一章，点击“创建／继续本章项目”，确认自动进入编辑器，已有 `CMakeLists.txt`、`main.cpp`，目标为 `native_lab`、原生 CMake、终端输出；首次运行得到 `Hello, TinaIDE!`。
- [ ] **修改与续开**：按第一章提示输出 `Hello, TinaIDE!` 和 `First change` 两行，保存。返回教程再次点击创建入口，确认仍是同一个工程，修改没有被覆盖；旋转屏幕、切到后台再回来后再检查一次。
- [ ] **失败与恢复**：删除 `return 0;` 的分号，保存并运行；应停留在构建日志并显示实际错误，不能把旧终端输出当作成功。恢复分号后应能重新构建运行。
- [ ] **章节验收**：在编辑器命令面板或更多菜单打开“验收当前课程章节”。先核对弹窗的项目名、章节名与当前练习一致；第一章参考版本应有上述两行输出。通过后返回教程检查完成标记与下一章入口。

自动验收检查的是练习参考版本，不是每章刚创建的基线。例如第二章基线固定数量为 3；需要完成输入和折扣练习，才符合自动验收输入。程序不应停在等待手工输入的状态再启动自动验收。
