# 关于与日志

关于页提供版本信息、社区入口、日志工具、开发者选项启用入口和开源许可证列表。捐赠支持已移到独立页面。

## 许可证与源码

打开 **设置 → 关于 → 开源组件与许可证**，选择 **TinaIDE** 或
**RikkaHub (TinaIDE embedded)**，可离线阅读随安装包附带的 GPL / AGPL 许可全文，
并通过项目主页链接访问源码。RikkaHub 使用上游纯 AGPL-3.0 许可，已无原来的非商业和用户数附加限制。
对外分发时仍须提供与 APK 匹配的源码；Release 页的递归检出命令包含子模块，普通 source ZIP 不包含它们。

## 捐赠支持

打开 **我的 → 捐赠支持**，入口位于 **设置** 下方、**关于** 上方。独立页面展示微信、支付宝赞赏码，并提供爱发电网页入口，方便支持项目的持续开发与维护。

## 日志

这里可以查看、导出或上传诊断日志。日志上传使用匿名诊断路径，可附带设备和运行环境信息。

上传前建议确认日志内容，避免分享敏感项目路径、命令输出或依赖名称。

## 开发者选项

连续点击版本信息可以启用开发者选项。这里提供诊断日志、服务端地址调试、测试工具和内置包重装入口。开源版不提供私有身份或商业功能入口。
