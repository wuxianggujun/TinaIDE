# 学习路线与功能索引

教程页提供两种学习入口：首次使用时的界面 Spotlight 引导，以及一套从创建项目、编辑 C++、构建排错到运行验证的连续实操课程。实操课程按章节保存进度，章节任务、代码样例和检查点只在教程中维护，不在帮助目录重复列出。

打开实操章节后点击 **创建／继续本章项目**，即可自动准备完整 CMake 和源码并进入编辑器，不需要逐个新建教程文件。九章使用独立工程，重复打开保留修改；源码保存在应用私有项目目录，可从项目列表继续打开或导出。创建不等于通过考核，也不会自动安装 fmt、SDL3 或调用 AI；依赖准备见对应章节。

本文作为帮助索引，侧重查资料而非重复教学：

- 编辑器操作与快捷键：查看[编辑器基础](editor-basics.md)和[快捷键](keyboard-shortcuts.md)。
- 构建参数与运行配置：查看[构建与运行](build-project.md)和[CMake 速查](cmake-guide.md)。
- vcpkg 接入：查看[CMake 使用 vcpkg](vcpkg-guide.md)。
- 遇到失败：先保留第一条有效错误、文件名、构建目标和实际输出，再按[构建指南](build-project.md)定位。

**教程**负责循序实践、步骤确认和续学；**帮助**负责可搜索的功能参考、参数说明与排错。项目页管理工程，市场管理插件、内置包和 vcpkg。RikkaHub 在编辑器侧边栏独立管理模型、渠道和 Key；课程中的模拟对话不会发送真实请求。
