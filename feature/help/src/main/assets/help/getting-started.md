# 学习路线：先运行，再理解，再扩展

从 **教程** 按下面路线实践。每课包含可操作步骤、输出或画面预期、故意失败后的恢复练习；确认实际结果后再标记完成。全部使用 Android 原生工具链，课程不要求 Linux 环境，也不要求配置 AI。

| 顺序 | 实践 | 完成时能做到 |
| --- | --- | --- |
| 1 | [从项目到运行](ide-workflow.md) | 创建、保存、构建、运行并定位语法错误 |
| 2 | [C++ 变量与控制流](cpp-basics.md) | 写计价器，验证输入与边界 |
| 3 | [函数与多文件](cpp-functions.md) | 拆分头文件与实现，区分编译和链接 |
| 4 | [字符串与容器](cpp-collections.md) | 使用标准库和算法，处理空数据 |
| 5 | [对象与资源生命周期](cpp-raii.md) | 理解 const、所有权和文件 RAII |
| 6 | [CMake 目标与库](cmake-practice.md) | 创建并链接库，不手填工具路径 |
| 7 | [CMake 使用 vcpkg](vcpkg-guide.md) | 添加 fmt、安装、链接并运行 |
| 8 | [SDL3 图形与事件](graphics-sdl3.md) | 修改模板绘制、处理触摸、检查日志与退出 |
| 9 | [AI 协作模拟练习](ai-practice.md) | 离线练习提问与审查建议，按需配置自己的服务 |

每课只改一个小目标。卡住时保留第一次相关错误、文件名、运行目标与实际输出，回到上一个可运行状态。不要反复删除项目或卸载 IDE。

## 教程与帮助各做什么

**教程** 用于按顺序动手、记录进度和继续下一课；**帮助** 用于查找参数、快捷键、运行契约和排错。二者读取同一份本地化正文，课程内的下一课链接直接继续教程，不需要重复阅读两份互相矛盾的说明。

**项目** 管理工程，**市场** 管理插件、内置包和 vcpkg，**我的** 提供设置与日志入口。编辑器侧边栏的 RikkaHub 独立管理 AI 模型、渠道和自己的 Key；课程中的模拟对话不发送真实请求。
