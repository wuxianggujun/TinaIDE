# Learning path: run, understand, extend

Open **Learn** and follow this practical sequence. Each lesson has actions, expected results, and recovery exercises. Mark it complete after verifying the result. The course uses the native Android toolchain and requires neither Linux nor an AI account.

| Step | Lab | Outcome |
| --- | --- | --- |
| 1 | [Project to execution](ide-workflow.md) | Create, save, build, run, and diagnose a syntax error |
| 2 | [C++ values and control flow](cpp-basics.md) | Validate input and boundary cases |
| 3 | [Functions and multiple files](cpp-functions.md) | Separate declarations and implementations |
| 4 | [Strings and containers](cpp-collections.md) | Use algorithms and handle empty data |
| 5 | [Objects and lifetimes](cpp-raii.md) | Understand ownership and file RAII |
| 6 | [CMake targets](cmake-practice.md) | Build and link a library |
| 7 | [Using vcpkg](vcpkg-guide.md) | Install, link, and run fmt |
| 8 | [SDL3 graphics](graphics-sdl3.md) | Change drawing, handle touch, and verify exit |
| 9 | [Mock AI collaboration](ai-practice.md) | Practice prompts offline and optionally configure your own provider |

Change one small thing at a time. Keep the first relevant error, file name, target, and actual output. Return to a working state instead of repeatedly deleting the project or uninstalling the IDE.

**Learn** provides a sequence and progress; **Help** provides searchable settings, shortcuts, runtime contracts, and troubleshooting. Both use the same localized content. Next-lesson links continue the course directly.

**Projects** manages work, **Market** manages plugins and packages, and **Profile** opens settings and logs. RikkaHub in the editor sidebar manages its own AI models, providers, and keys. Course examples make no live requests.
