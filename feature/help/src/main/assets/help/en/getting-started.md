# Getting Started

TinaIDE Open Source focuses on local Android C/C++ development, plugins, package management, and terminal workflows. AI chat, models, providers, and credentials are supplied by the embedded RikkaHub.

## Main areas

- **Projects** — create, open, import, and manage projects.
- **Marketplace** — browse and install plugins or development packages.
- **Tutorials** — read the built-in help documentation.
- **Me** — open Settings, About, and download history.

## Open-source scope

The public app does not include private identity or commercial services. Logs, plugins, package downloads, favorites, and download history remain available.

For AI features, open RikkaHub from the editor sidebar. Configure providers, models, MCP, assistants, and API keys inside RikkaHub.
