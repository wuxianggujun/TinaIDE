# Learning path and feature index

Tutorials offers two entry points: a first-use Spotlight tour and one continuous hands-on course covering project creation, C++ editing, build troubleshooting, and runtime verification. The course stores progress by chapter; its tasks, examples, and checkpoints are maintained in Tutorials rather than duplicated in the Help catalog.

Tap **Create / resume chapter project** in a practice chapter to prepare complete CMake and source files and open the editor, without creating tutorial files manually. Each of the nine chapters uses an independent project; reopening preserves edits. Sources live in app-private project storage and can be reopened or exported from Projects. Creation does not pass an assessment, install fmt or SDL3, or make AI requests; follow the chapter for dependencies.

Use this Help page as a reference index:

- Editor behavior and shortcuts: [Editor basics](editor-basics.md) and [Keyboard shortcuts](keyboard-shortcuts.md).
- Build options and run configuration: [Build and run](build-project.md) and [CMake reference](cmake-guide.md).
- vcpkg integration: [Using vcpkg with CMake](vcpkg-guide.md).
- When something fails, keep the first actionable error, file name, build target, and actual output, then consult [Build and run](build-project.md).

**Tutorials** is for sequential practice, checkoffs, and resuming progress. **Help** is for searchable feature references, options, and troubleshooting. Projects manages workspaces; Market manages plugins, built-in packages, and vcpkg. RikkaHub in the editor sidebar independently manages AI models, providers, and keys; simulated course conversations do not send live requests.
