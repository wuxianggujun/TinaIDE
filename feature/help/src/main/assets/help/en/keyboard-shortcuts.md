# Keyboard Shortcuts

TinaIDE provides a focused shortcut set for hardware keyboards. Shortcuts can be customized in Settings.

## Default shortcuts

| Shortcut | Action |
|---|---|
| Ctrl + S | Save current file |
| Ctrl + Shift + S | Save all files |
| Ctrl + W | Close current tab |
| Ctrl + Shift + W | Close all tabs |
| Ctrl + Tab | Next tab |
| Ctrl + Shift + Tab | Previous tab |
| Ctrl + Z | Undo |
| Ctrl + Shift + Z | Redo |
| Ctrl + F2 | Toggle bookmark |
| F2 | Next bookmark |
| Shift + F2 | Previous bookmark |

## Customize shortcuts

Open **Settings → Keyboard**. Select an action, press the new key combination, then confirm. TinaIDE detects conflicts and can restore one action or every action to its default.

## Hardware keyboard requirement

Bluetooth, USB, and keyboard-cover devices provide the most reliable events. Many software keyboards do not report Ctrl, Shift, Alt, or F2 combinations consistently.

Editor shortcuts are separate from the terminal extra-key row. The terminal row supplies command-line control keys such as Ctrl, Alt, and Esc.
